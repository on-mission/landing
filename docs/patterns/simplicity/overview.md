# Simplicity

Simple code exposes the product decision directly. It does not mean short code,
few files, or no abstraction; it means no machinery without a present reason.

## Leaf

- [Simplicity rules](simplicity.packet.md) — earn abstraction, keep control flow
  local, and remove speculative extension points

Simplicity works with [domain design](../domain/overview.md): the domain decides
where behavior belongs, and the smallest durable shape expresses it there.
