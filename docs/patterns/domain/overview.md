# Domain design

Code should let a competent reader recognize Landing: routes, tiers,
connections, availability, dispatches, continuations, and project configuration.
The domain disappears when files and exports are named for generic procedures,
value shapes, or implementation themes.

## Leaves

- [Ownership and naming](ownership.packet.md) — one cause, one concept, and a
  domain-shaped export boundary
- [Extraction](extraction.packet.md) — duplicate by default and abstract only
  when drift has a concrete consequence

The [domain engineer corpus](../../../utilities/personas/domain-engineer/README.md)
contains that persona's deeper doctrine and calibration examples, inherited
from the project this catalog grew out of. Landing adopts the portable
cause-and-drift tests, not that source's specific manager topology.
